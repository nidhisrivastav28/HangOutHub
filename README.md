# 🌟 HangoutHub

HangoutHub is a **mood-based hangout suggestion platform** that helps users quickly find places based on **mood, budget, and location**.  
It solves the real-life problem of spending too much time deciding where to go with friends – and often ending up at the same places 😅.

## ✨ Features
- Mood + Location + Budget-based place recommendations  
- Option to search using **current location** or a **specific place**  
- Secure login & user management  
- Rating & feedback system  
- Responsive, user-friendly design  

---

## ⚙️ Tech Stack
- **Backend:** Spring Boot  
- **Frontend:** Thymeleaf, HTML, TailwindCSS, JavaScript  
- **Database:** MySQL
